### Credit Loan Analysis Dashboard

A professional Power BI dashboard designed to evaluate customer credit risks, analyze demographics, and track loan approval metrics. This interactive dashboard provides comprehensive insights to optimize credit management strategies and decision-making processes.

### 🎯 Key Objectives & Insights

* Demographic Breakdown: Visualizes customer distribution by Gender and Marital Status to identify key borrowing segments.
* Credit Score Analysis: Tracks customer net income alongside historical credit scores to gauge repayment capabilities.
* Risk Management: Highlights missed payments and unsecure loans to help minimize operational defaults.

### 🛠️ Tools & Technologies Used

* Power BI Desktop: For data transformation (Power Query), data modeling, and creating interactive visualizations.
* Data Visualizations: Donut Charts, Stacked Column Charts, KPIs, and Matrix views for clean reporting.
